# Video license and image credits

`driving-walkthrough-90s.mp4` is a captioned screen recording by Yike Chen of this repository's saved-model explorer. It includes camera images from **nuScenes v1.0-mini**, published by **Motional**. The recording adds interface overlays, English captions, model scores and review examples; it does not alter the source camera images.

The repository's MIT license covers its code; it does not relicense the dataset images or this video.

Dataset citation: Holger Caesar et al., *nuScenes: A multimodal dataset for autonomous driving*, CVPR 2020. [Dataset website](https://www.nuscenes.org/) · [Paper](https://arxiv.org/abs/1903.11027).

The video presents an academic project pilot. Motional has not sponsored or endorsed this project. Source-image filenames and SHA-256 values are recorded in the explorer's embedded manifest; the recording receipt identifies the exact viewer and original ZIP inputs.

The displayed predictions are saved outputs from the documented CPU run. References came from a single reviewer after AI-label disclosure; the recording creates no new judgments or benchmark results. See the [recording evidence](../results/presentation-english-20261029/README.md).
