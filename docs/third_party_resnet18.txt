ResNet18 CPU encoder attribution

scripts/cpu_image_encoder.py adapts the standard BasicBlock and ResNet18
architecture from torchvision v0.20.1:
https://github.com/pytorch/vision/blob/v0.20.1/torchvision/models/resnet.py

The adaptation supports the standard ResNet18 architecture only, retains the
1000-class fc parameters to strictly verify the official full state dictionary,
and returns the 512-dimensional avgpool representation without applying fc.
Torchvision is not a runtime dependency. ResNet18 is an existing architecture;
this project's addition is the six-camera CPU extraction and experiment route.

Pretrained weights are the official ImageNet1K V1 checkpoint:
https://download.pytorch.org/models/resnet18-f37072fd.pth
SHA256: f37072fd47e89c5e827621c5baffa7500819f7896bbacec160b1a16c560e07ec
The local implementation uses float32 inference and the documented ImageNet V1
bilinear resize-short-side 256, center crop 224 and ImageNet normalization.
