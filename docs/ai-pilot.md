# Real mini CPU pilot with provisional AI labels

This page preserves the original 2026-10-23 AI-reference experiment. The later
[AI recheck](../results/ai-label-recheck-20261024/README.md) and
[single-reviewer run after AI-label disclosure](../results/human-ai-exposed-20261026/README.md)
are separate experiment records. The [review workflow](human-review.md) explains
their annotation provenance.

This run completed ingestion, frozen scene allocation, CPU features, four-model
training, checkpoint reloads, saved-prediction evaluation and unlabelled
screening on real nuScenes mini images on 2026-10-23. Labels were generated by
the in-session Codex visual assistant, **not verified by a human**. All numbers
below measure agreement with those provisional labels. They are not benchmark
accuracy, a replication of Cosmos features, or evidence of a tail-reward gain.

## Inputs and decisions

The user supplied four locally generated parts from `v1.0-mini.tgz`. All 480
original JPEGs, five original metadata tables and their recorded hashes passed
import and independent checks. The original multi-gigabyte archive checksum
was not independently verified. The [extraction record](real-mini-cpu-run.md)
describes the 80 timestamps / ten scenes / `(80, 3072)` ResNet18 feature cache.

Four AI annotators collectively inspected all 80 six-camera panels, with original
camera images enlarged for ambiguous cases. They received the frozen rubric
and image identities without split assignments, scene descriptions or model
outputs. An additional AI pass blindly inspected 16 predetermined timestamps:
15 decisions agreed and one differed. That is AI-to-AI agreement, not a human
accuracy estimate. Any disagreement stays uncertain; original decisions and
visible evidence are retained.

The final provisional decisions were 13 `normal_core`, 60 `not_normal_core`
and seven `uncertain`. Uncertain rows were excluded, without changing scene
allocation or adjusting labels to class balance:

| Frozen internal split | Scenes | Normal | Tail | Included frames |
|---|---:|---:|---:|---:|
| Train | 6 | 3 | 45 | 48 |
| Validation | 2 | 5 | 6 | 11 |
| Test | 2 | 5 | 9 | 14 |

The 6/2/2-scene mini allocation was frozen before any labels. Mini has no
official test split. Three normal training frames, two test scenes and
unverified labels sharply limit interpretation.

Before annotation/model results, the pilot fixed seed 42, ten epochs, hidden
width 256, AbsTopK 32 and a review budget of four. All methods share the same
features, retained labels, manifest and source snapshot. Normalization is fitted
on train; checkpoints and the 90% precision operating point use validation.
No test threshold tuning or multi-seed result is reported.

## Observed results against AI references

| Method | Test AP | Precision at 4 | AI-tail references found / 4 | Validation-selected test recall |
|---|---:|---:|---:|---:|
| Logistic regression | 0.5857 | 0.50 | 2 | 0 |
| Small MLP | 0.5404 | 0.25 | 1 | 0 |
| AbsTopK SAE, no reward | 0.9216 | 1.00 | 4 | 0 |
| AbsTopK SAE, norm reward | 0.9216 | 1.00 | 4 | 0 |

Uniform random sampling would find 2.57 of the nine AI-tail references in an
expected four-of-fourteen selection. This is an expectation, not an executed
random-sampling experiment or a claim about review time saved.

All four validation precision targets were unreachable. The pre-existing rule
therefore returns `threshold=null` and predicts none, giving test recall zero.
The SAE's original activation rule instead flags every test frame, producing
five false positives and zero false negatives relative to the AI references.
Ranking, fixed-rule classification and validation-selected operation are
distinct outputs and must not be combined into a single success claim.

The reward/no-reward SAE checkpoints are byte-identical. Train-only diagnostics
found all 45 tail norms above the default cap of two even at initialization;
the reward gradient was zero and the total gradients with/without reward were
identical. The saved train tail norms ranged from 3.46 to 6.94. Both ten-epoch
loss histories differ by a constant one and choose epoch three. The original
cap is preserved; no coefficient was tuned or extra run selected using test
scores. This pilot does not establish an incremental reward benefit.

## Inspection and reproduction

`output/real-cpu-mini-20261023/ai-pilot/` retains the AI annotations, visible
evidence, blind-pass record, original annotation hashes, frozen pilot plan,
imported AI-only manifest, exact commands, logs and four complete run bundles.
Every run includes checkpoint, predictions, evaluation JSON, PR data/figure,
feature/manifest hashes, resolved dependencies and the source snapshot actually
used. The independent audit reloaded all four models and reproduced scores,
train-only normalization, thresholds and the main table.

Seven uncertain timestamps, absent from fitting/validation/test by token, were
screened using the saved SAE and unchanged training scaler. Their scenes can
overlap the labelled scenes: this is an unlabelled inference smoke, not another
spatial/generalization test. Their exported human-review fields are blank.

The offline demo uses the neuron explorer and opens the user's same
four local ZIPs. It displays trained activations, six original views, similar
high-activation examples, method scores, AI-reference errors and a review CSV.
No original image bytes are embedded in its downloadable HTML. Units retain
numeric identifiers; no old Cosmos glossary or invented semantic name is used.
The original sandbox denied loopback HTTP binding. That failed check remains
in the run record; API, image and CSV checks alone did not verify browser use.

The final local suite passed 205 tests and 18 subtests, with the socket-dependent
HTTP test deselected. The optional real-asset test actually ran against this
real feature bundle and explicitly AI-provisional labels. Lint passed. Offline
Node checks matched all 292 displayed model predictions to saved outputs and
validated all 480 local images. A later
[GitHub Actions Chrome run](https://github.com/CCC917111/long-tail-driving-scene-discovery/actions/runs/40039920157)
passed desktop/mobile image rendering, unit/sample navigation, search and CSV
download using synthetic, watermarked ZIP fixtures. Its three runtime scripts
are byte-identical to the shipped explorer. This verified the UI with synthetic
images, separately from the real-image byte/score checks. The retained
[browser CI report](../results/cpu-mini-ai-pilot-20261023/browser_ci_verification.json)
records that scope. CPU CI also passed tests, lint and the generated-data HTTP
workflow on the same head; see [testing](testing.md).

Download the [archived AI-reference demo](../demo/driving_ai_pilot.html), save the HTML and open
it in desktop Chrome/Edge, then select the same four original ZIPs. The
[derived result bundle](../results/cpu-mini-ai-pilot-20261023/README.md) records
provisional labels, saved scores, diagnostic evidence and hashes. Original
images, raw metadata tables and trained model weights are not published there.

AI inputs require a separate importer and explicit opt-in:

```bash
python scripts/ai_pilot_labels.py \
  --prepared-dir output/real-cpu-mini-20261023/prepared \
  --annotations output/real-cpu-mini-20261023/ai-pilot/ai_visual_labels.json \
  --output-dir output/real-cpu-mini-20261023/ai-pilot/annotations

python scripts/run_real_driving.py train \
  --feature-protocol cpu-resnet18 --label-protocol ai-visual-pilot \
  --prepared-dir output/real-cpu-mini-20261023/prepared \
  --annotations-dir output/real-cpu-mini-20261023/ai-pilot/annotations \
  --extract-dir output/real-cpu-mini-20261023/extract --layer 1 --pooling mean \
  --output-dir output/real-cpu-mini-20261023/ai-pilot/comparison_runs \
  --review-k 4 --seed 42 --epochs 10 --hidden-dim 256 --k 32
```

Use fresh output directories; the commands above describe the preserved run.
The default manual-label workflow rejects an AI bundle. Each AI row, metric,
comparison row and demo retains the AI-provisional/human-pending scope.

Stronger model claims require independent human decisions and more diverse
normal and tail scenes under a predeclared review budget. Any change to the
reward cap needs train-only diagnostics and a new protocol; it cannot be
presented as a gain from this preserved run.
